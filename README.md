# Rich With Reason

Site for richwithreason.com, served by GitHub Pages.

- `tools/shell.html`: page template (header, home sections, footer, link-preview tags)
- `assets/site.css`, `assets/site.js`: styles, topics (`CATS`) and articles (`ARTICLES`)
- `index.html` and the topic and article folders (`banking-credit/…`) are generated. After adding or editing
  articles, run `node tools/build-pages.mjs` and commit the result.
